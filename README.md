# RNA-based multitarget therapy to restore gene networks and prevent cancer-induced cachexia

This repository contains the scripts developed for the analysis of single-nucleus multiome, bulk sequencing, and spatial transcriptomics data.

## Authors

- Davide Risso (davide.risso@unipd.it)
- Giuseppe Persico (giuseppe.persico@unipd.it)
- Elena Zuin (elena.zuin.3@phd.unipd.it)

## Repository Structure

  -   bulk/: script for bulk multiome analysis, including differential expression analysis and transcription factor binding sites
  -   multiome/: scripts for single-nucleus multiome analysis, including quality control, multi-omics integration, cell type annotation, downstream analysis, cell-cell communication, and transcription factor binding sites;
  -   spatial/: scripts for spatial trascriptomic analysis, including alignment, exploratory data analysis, and downstream analysis.
